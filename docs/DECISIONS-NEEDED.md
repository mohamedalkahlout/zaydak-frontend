## تفاصيل الشغل المتبقي على المال (ليست إعادة قرار)

### عمولة (P1 — بدأت)
- عمود `Balance.gross_sales_cents` + backfill صفين (`prisma/manual/2026-09-17-balance-gross-sales-cents.sql`)
- `resolveCommissionBps` يقرأ `is_custom_commission` ثم شرائح `Commission` على الحجم لا على `current_balance`
- الاسترجاع يستخدم لقطة `Order.commission_bps` فقط
- **محجوب على إنتاج:** `npm run inspect:money-launch` ثم seed الشرائح

### ائتمان مكرَّر (P0 إنتاج)
- `npm run inspect:money-launch` — قراءة فقط
- `npm run remediate:duplicate-credits` — dry-run افتراضي؛ `--apply` بعد مراجعة بشرية؛ يرفض host غير loopback بلا `ALLOW_REMOTE_REMEDIATE=1`

### Redis
- ترقية فورية عن الخطة المجانية — حاجز تشغيل (B30). إعدادات العميل المحلية hardened مسبقًا (`enableOfflineQueue: false`, `maxRetriesPerRequest: 1`).
